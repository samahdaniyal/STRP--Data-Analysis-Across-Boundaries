# STRP--Data Analysis Across Boundaries

## Overview

**Data Analysis Across Boundaries** is a data-driven project aimed at supporting policymakers in Muslim-majority countries by providing insightful, interactive visualizations based on global datasets. This project was developed as part of the **Summer Tehqiq Research Program (STRP-1)** by the **Graduate School Curation Program - Habib University**. [Link to Our Dashboard](https://app.powerbi.com/view?r=eyJrIjoiYzBjOTE1NTQtOTExNS00NDdlLWI1YzMtM2VmN2VmOGQ3MWJiIiwidCI6IjcwYzM1YWE0LWJlZDQtNDhmMi05NWM5LWUzYmEyZjdjMDM3YSIsImMiOjl9)

## Project Goals

- Facilitate data-driven decision-making for policymakers
- Aggregate, clean, and consolidate large-scale global datasets
- Develop interactive dashboards to visualize trends across multiple domains

## Data Sources

We utilized comprehensive datasets from:
- **World Data Bank**
- **OICStat**
- **Climate Action Dashboard**

## Tools & Technologies Used
- **Python** (Data cleaning & processing)
- **SQL** (Database management & querying)
- **MSSQL** (Data consolidation & storage)
- **Power BI** (Interactive dashboard development)

## Key Features

### Data Collection & Cleaning
- Aggregated and cleaned datasets from multiple global sources to ensure accuracy and consistency.
- Standardized data formats for seamless integration into a unified database.

### Data Consolidation & Visualization
- Consolidated large datasets into an **MSSQL** database for streamlined analysis.
- Developed and deployed **interactive dashboards** using **Power BI, MSSQL, and Python**, allowing stakeholders to explore trends in **health, economy, climate, and more**.

### Research & Technical Proficiency
- Conducted a literature review to identify key indicators and data dimensions relevant to Muslim-majority countries.
- Evaluated multiple data repositories and analytical tools to ensure reliability and relevance.

### Collaboration & Teamwork
- Worked with a **multidisciplinary team** to integrate and analyze datasets.
- Contributed to key milestones, including data integration, visualization, and preliminary analysis.

## Project Outcomes
- Successfully built an interactive dashboard to support policymakers in **understanding complex data trends**.
- Contributed to the pilot project’s completion, enhancing data accessibility for informed decision-making.
- Strengthened expertise in **data science, visualization, and collaborative research**.
